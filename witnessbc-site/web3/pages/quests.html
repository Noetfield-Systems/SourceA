Quest 01 / Verification

Reproduce an
agent policy outcome.

80 XP · APPROVED ONLYTESTING

Choose a policy decision, state inputs and expected output, reproduce it, then publish a sanitized report of the result. A screenshot alone without context is insufficient.

Try an example ↗
ACCEPTANCE CRITERIA
  • Scenario and policy condition stated
  • Steps to reproduce and observed outcome
  • Public artifact or shareable test note
  • No private keys, client data or secrets
  • Human review before XP is awarded
Quest 02 / Engineering

Write a rule.
Prove it works.

150 XP · APPROVED ONLYDEVELOPMENT

Publish one practical policy rule for an AI agent with clear inputs, observable verdict and an independently reproducible passing test.

ACCEPTANCE CRITERIA
  • A scoped rule and a reason for the rule
  • Public code or exact pseudocode
  • At least one expected test and its result
  • A documented safe replay procedure
  • Human verification before reputation credit
Quest 03 / Open knowledge

Teach one thing
that matters.

100 XP · APPROVED ONLYCREATION

Create an original guide, developer walkthrough, demo or explanation of how governance decisions can be tested and reviewed in a Web3 community.

ACCEPTANCE CRITERIA
  • Accessible public learning artifact
  • Clear original authorship and source credits
  • A concrete working scenario or demonstration
  • Steps readers can follow independently
  • Human assessment and constructive feedback
